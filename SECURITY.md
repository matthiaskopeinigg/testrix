# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `1.0.6` (latest stable) | Yes |
| `1.0.x-beta` prereleases | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

1. Use [GitHub Security Advisories](https://github.com/matthiaskopeinigg/testrix/security/advisories/new) for private disclosure, or
2. Contact the maintainer via their GitHub profile: [matthiaskopeinigg](https://github.com/matthiaskopeinigg)

Include steps to reproduce, affected versions, and impact. We aim to acknowledge reports within **7 days** and to share a remediation plan when feasible.

See [docs/security.md](docs/security.md) for architecture-level security notes.
